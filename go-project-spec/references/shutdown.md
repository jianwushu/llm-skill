# 装配与关闭

装配代码只做一件事：按依赖顺序创建资源、登记释放函数、把资源交给下一个组件。不做业务判断，不吞错误。

## 顺序

`配置加载 → 配置校验 → 日志初始化 → 数据库 → 外部客户端 → service/handler → server → daemon 启动`。

日志必须在配置校验之后、其他组件之前——否则前面组件的初始化日志全丢。模板的 `cmd/server/main.go` 就是这个顺序，照抄不要凭记忆重写。

**创建资源的代码只在 `main.go`**。`server.New` 只接收建好的 handler 与 frontend，不创建 repo / client / engine——创建即产生关闭义务，放进 server 就等于 server 自己持有一份 closer，关闭逻辑立刻变成两份，且 server 初始化中途失败时那份还没登记。

## 关闭逻辑只能有一份

```go
var closers []func() error
defer func() {
    for i := len(closers) - 1; i >= 0; i-- {
        if cerr := closers[i](); cerr != nil {
            slog.Warn("close resource failed", "err", cerr)
        }
    }
}()
```

闭包捕获的是变量本身，后面 append 进来的也会被执行。

**必须避开的写法**：用 `ok := false` 标记"是否正常结束"，`defer` 里 `if ok { return }`——正常退出时直接跳过，所有 closer 都不执行，DB 连接与日志句柄全部泄漏。

这种写法把「装配失败回滚」和「正常退出关闭」当成两件事，实际是一件事：**资源总要释放，区别只在错误往哪报**（装配期打到 stderr，运行期打到日志）。

## 关闭顺序

```
停止接收新工作（HTTP Shutdown / daemon Pause）
 → 等在途排空（带超时上限，如 30s；超时强制继续）
 → 关闭外部客户端（HTTP 空闲连接 / MQTT / Redis / MQ）
 → 关闭数据库
 → 关闭日志（最后）
```

- **日志最后关**：提前关会丢掉"关闭过程中"的错误日志，恰好是排障最需要的。
- 每个 closer 必须**幂等**：重复 Close 返回"已关闭"错误即可，不要 panic。
- 排空必须有超时上限，否则一个卡住的任务能让停机无限挂起，运维只能 `kill -9`，等于丢数据。

## 可选依赖降级

可选组件（远端库、缓存、MQ、外部工具链）不可用时不要让进程起不来：失败就 `slog.Warn` 降级，不 append closer，继续装配。

- 使用处检查 `nil`，返回**明确错误**（"远端库未启用/不可用"），不要 nil pointer panic。
- 降级必须 `Warn`，并尽量在健康检查里体现，否则运维不知道某项能力已缺失。
- **必需依赖仍然 fail fast**：配置非法、主库连不上就拒绝启动。降级只针对可选组件。

## 信号与退出码

- `signal.NotifyContext` 收 `os.Interrupt` + `syscall.SIGTERM`，把 ctx 一路传下去。
- 正常退出返回 0；装配/运行失败返回 1。
- **预期情况必须返回 0**：如"配置文件刚生成并退出"，返回非 0 会被守护进程判定崩溃并反复重启。
- Windows 上 `SIGTERM` 无法显式发送，靠 `os.Interrupt`（Ctrl+C）；服务化部署用系统服务管理器的停止机制。

## 反模式

| 反模式 | 后果 | 正确做法 |
|---|---|---|
| 正常退出跳过 closer | 连接/句柄泄漏 | 关闭逻辑只写一份，永远执行 |
| 中途失败直接 `os.Exit` | 已建资源不回滚 | 返回 error，由 defer 回滚 |
| 日志先关 | 关闭期错误日志丢失 | 日志最后关 |
| 排空无超时 | 停机卡死 | 带超时上限 |
| closer 不幂等 | 重复关闭 panic | 幂等实现 |
| 可选依赖失败即退出 | 主功能其实用不到它 | 降级 + Warn + 健康检查体现 |
| 装配里写业务判断 | 无法测试、难排障 | 只做创建与登记 |

## 校验

```bash
# 1) 中途失败回滚：DB 路径指向不可写目录 → 启动失败且不留残留
# 2) 正常退出：Ctrl+C 后确认最后一条日志是优雅停止
# 3) 排空：常驻任务运行时发信号，确认在途任务跑完再退出且不超上限
```
